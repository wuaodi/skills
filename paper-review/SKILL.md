# paper-review

以挑剔审稿人的视角把论文过一遍，把每个问题定位到具体位置（章节 / 行 / 图表号 / 公式号 / bib key），按严重程度给出可执行的修改建议。中英文论文通用。

## 使用前

- 拿到全文：正文、图表、参考文献或 .bib。缺哪部分就在报告里标注"未提供，无法核验"。
- 先通读一遍，弄清论文的核心主张和 story，再逐维度挑问题。
- 只挑真问题并给改法，不做无依据的表扬。

## 检查维度

### 1. 逻辑自洽
- 动机 → 方法 → 实验 → 结论的链条是否闭合，有无断裂或循环论证。
- 前后主张是否一致，方法描述与实验设置、结论有无互相矛盾。
- 每个结论都能在正文找到对应支撑。

### 2. 证据充分
- Abstract 与 Introduction 的每个主张是否有实验数字或文献支撑，建 claim-evidence 表逐条核对。
- 正文的数字、百分比、提升幅度是否和图表一致。
- 消融与 baseline 是否真的支撑所下的结论，有无过度声称。

### 3. 文字规范
- 一段一个中心，首句点题，句间有明确衔接。
- 术语和数学记号全文统一，缩写首次出现即定义。
- 英文时态 / 单复数 / 冠词一致；中文用词书面、规范。
- 无 AI 味：按 no-ai 技能的口癖清单排查，并遵守本仓库 AGENTS.md（避免 `xxx: Xxxx` 子标题、长破折号、大量括号注释、罗列 1234、"不是 X 而是 Y"）。

### 4. 图表规范与美观
- 每张图 / 表都被正文引用，且引用的编号正确。
- caption 能自解释；坐标轴有标签和单位，图例齐全。
- 表格精简（minimal-ink），最优值加粗，指标注明方向（↑ / ↓）。
- 字号在缩放后仍可读，配色统一，teaser 与 pipeline 图能清晰传达核心。

### 5. 引用正确
- 每处引用的内容与被引文献的真实结论一致，没有张冠李戴。
- \ref / \eqref / \cite 没有出现 `??`，编号对得上。
- \citet 与 \citep（或 \cite）用法是否正确；有无未被正文引用的 bib 条目、重复条目。

### 6. 参考文献真伪（重点）
- 逐条核对 .bib：标题、作者、年份、会议 / 期刊、页码、DOI / arXiv 号是否真实存在且互相吻合。
- 标出疑似 AI 幻觉生成的条目：作者与标题不匹配、会议名或年份对不上、DOI 无法解析、同一篇被拼接成不存在的文献。
- 无法核实的标为"待人工核验"，并给核对建议：DOI、arXiv、Semantic Scholar、DBLP。

### 7. 定义清晰
- 每个新概念 / 符号先定义后使用，没有先用后定义。
- 同一符号不承担两种含义；变量的取值域 / 维度有说明。
- 关键术语在全篇含义稳定。

### 8. 无冗余
- 重复的句子和段落、反复出现的空话套话。
- 可以删掉而不损失信息的过渡词和限定词。

### 9. 无低级错误
- 拼写、语法、标点；中英混排的空格，中文标点用全角。
- 公式符号、下标、单位是否一致，量纲对不对。
- 图 / 表 / 公式 / 章节编号连续且无跳号。
- LaTeX 层面：未定义引用、缺 \label、overfull box、图片路径缺失。

### 10. 接受风险（可选深入）
- 贡献是否充分、实验是否强、评估是否完整、方法是否合理，见 research-paper-writing 技能的 references/paper-review.md。

## 输出格式

按严重程度分三档，全部定位到具体位置并给改法：
- 【严重】逻辑 / 证据 / 事实错误，或虚假引用，必须改。
- 【建议】影响清晰度或规范性，应该改。
- 【可选】锦上添花。

报告结构：

1. 总体判断：一段话说清最大的几个风险。
2. 分维度问题清单：每条写「位置 | 问题 | 级别 | 修改建议」。
3. Claim-Evidence 表：主要主张逐条写 `主张 | 证据位置 | 状态（支撑 / 需补证据 / 未支撑）`。
4. 参考文献核验表：`bib key | 是否可核实 | 问题`。
5. 低级错误清单：逐条列位置和订正。

## 工作流

1. 通读全文，写下核心主张和 story。
2. 逐维度检查，把问题定位到章节 / 行 / 图表号 / 公式号 / bib key。
3. 引用和参考文献逐条核验，重点抓虚假文献。
4. AI 味用 no-ai 技能过一遍。
5. 汇总成上面的分级报告，每条都给可执行改法，按严重程度排序。
