# 中文 Git 提交

标题为 `YYYYMMDD 类型：一句话说明`，日期取提交当天，类型按改动选新增、修复、更新、重构、文档或测试。正文简述目的、更改、验证；


## 大文件与归档
- 排除密钥、可再生成的构建产物、缓存、批量日志和实验输出；必要的发布资源按项目要求保留。
- 单文件超过 10 MB，先确认入库必要性；超过 50 MB 保留本地，按仓库约定排除出 Git，并说明未推送的文件，不用 Git LFS。
- 仅在用户明确要求归档时生成本地归档包。提交、推送、更新上下文或已有归档约定均不构成归档授权。
